- DatabaseToolRefactored:

  - `_execute_query(entity, entity_id)` generic method that validates entity, builds a parameterized query (using `?` placeholder), opens a connection context, executes the query and formats rows.
  - `_execute` is abstract-like; tests patch it. `_create_connection` returns a simulated connection; context manager handles closing.
  - Backwards compatibility: `query_users`, `query_products`, `query_orders` wrappers call the generic method.
- APIToolRefactored:
  - `_get_headers()` centralizes headers with API Key.
  - `_make_request(path, params)` makes the call using `requests.get`, checks status codes, and uses the `BaseTool` error decorator.
  - Wrappers: `fetch_weather`, `fetch_news`, `fetch_stock_price`.
